# /grill-me — Interactive Design Alignment

Follow this procedure when triggered:
1. Identify underspecified requirements in `.ai/CURRENT_SPEC.md` or user request.
2. Formulate 3-5 concise, targeted technical choices or architectural questions.
3. Present alternatives with pros/cons.
4. Record decisions in `.ai/DECISION_LOG.md` once user responds.
